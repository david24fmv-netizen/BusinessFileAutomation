# 🗂️ Business File Automation & Local History
Sistema en Python modularizado para la organización y seguimiento local de archivos corporativos con registro persistente (`history.json` + `database.py`).

## 📁 Estructura del proyecto
- `main.py`: Punto de entrada de la aplicación.
- `automation.py`: Lógica de movimiento/clasificación de archivos.
- `database.py`: Manejo de registros y persistencia de estado.
- `history.json`: Historial de operaciones locales.

## 🚀 Requisitos
Revisa el archivo `requeriments.txt` (o instala las dependencias de tu entorno).

## 💻 Ejecución
```bash
python main.py
